# 🛸 Консольный симулятор пожарного вертолёта (Курсовой проект)

Динамическая консольная игра на Python с использованием объектно-ориентированного программирования (ООП). Игрок управляет вертолётом, спасает лес от пожаров, борется с погодными условиями и улучшает свои характеристики.

## 📁 Структура проекта и архитектура

Проект профессионально разделён на независимые модули по принципу разделения обязанностей:

*   `main.py` — Главный игровой контроллер. Отвечает за систему игрового времени (тики), плавную анимацию кадра и мгновенный отклик клавиш управления.
*   `map.py` — Модель игрового мира. Генерирует реки и живой лес, отрисовывает графику с помощью цветных эмодзи в консоли и управляет автоматическим прорастанием новых деревьев.
*   `helicopter.py` — Класс вертолёта. Описывает логику передвижения, проверку границ мира, забор воды над реками и тушение горящих клеток.
*   `fires.py` — Менеджер пожаров. Отвечает за случайное появление огня, реалистичное распространение пламени на соседние деревья и их выгорание до золы.
*   `clouds.py` — Менеджер погоды. Генерирует плывущие по ветру облака и грозовые тучи, которые могут тушить огонь или бить молниями, отнимая здоровье у игрока.
*   `shop.py` — Магазин улучшений и Госпиталь. Позволяет тратить набранные очки на ремонт прочности вертолёта или апгрейд максимального объёма водяного бака.
*   `exporter.py` и `importer.py` — Модули сериализации данных. Реализуют сохранение текущего состояния мира и параметров игрока в файл формата JSON и моментальную загрузку игры.

## 🎮 Управление в игре
*   `W`, `A`, `S`, `D` — Передвижение вертолёта по карте (вверх, влево, вниз, вправо).
*   `H` — Посетить Госпиталь (лечение HP за очки).
*   `U` — Посетить Магазин (улучшение бака за очки).
*   `K` — Сохранить игру (Экспорт состояния).
*   `L` — Загрузить игру (Импорт состояния).
*   `Q` — Выход из игры.
